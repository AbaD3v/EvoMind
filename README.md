# EvoMind Web

Статический интерфейс EvoMind: чат, ход решения и библиотека инструментов. Подключается к [EvoMind Space](https://huggingface.co/spaces/AbaD3v/MoonAI-8B_qlora_Qwen3) через Gradio Client. Обучение модели выполняется отдельно.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm install
npm run dev
```

Открой http://127.0.0.1:4173. Для публикации достаточно статических файлов из корня и папки `assets`; сборка не требуется. Node.js и Playwright нужны только для локальной разработки и проверок.

## Интерфейс

- Стиль Obsidian: нейтральные графитовые поверхности, мятные акценты, крупная типографика, пронумерованные шаги и единое оформление диалогов и инструментов. Inter с латиницей и кириллицей хранится локально в `assets/`; лицензия — SIL Open Font License.
- Ответы: заголовки, выделение, списки, цитаты, таблицы, ссылки и код с копированием. Это безопасное подмножество Markdown; HTML из обычного ответа не исполняется, LaTeX отдельно не рендерится.
- Python и JSON получают безопасную лексическую подсветку, которая сохраняет исходный текст при копировании. Неизвестные языки и большие фрагменты показываются обычным текстом.
- Рабочая область: кнопка «Открыть результат» у каждой Markdown-таблицы открывает таблицу рядом с чатом (на телефоне — отдельным окном). Доступны столбчатый и линейный графики, выбор подписей и числового столбца, скачивание CSV. Работает и для ответов из истории.
- Графики строятся локально по данным таблицы: пропуски не превращаются в нули, проценты не смешиваются с обычными числами. Точка и запятая читаются как десятичный разделитель, пробел — как разделитель тысяч; произвольные единицы и экспоненциальная запись остаются текстом. Линия соединяет категории в порядке строк, а не по числовому расстоянию между подписями.
- В рабочей области показаны до 500 строк таблицы и 60 точек графика с явным уведомлением об ограничении. CSV содержит все строки, UTF-8 BOM и защиту от формул при открытии в электронных таблицах. Исходные данные и история чата не изменяются.
- Пример «Таблица → график» на стартовом экране использует явно помеченные учебные данные; он не вызывает модель и не добавляется в историю.
- Запросы: остановка ожидания, повтор после ошибки, понятные состояния сети, авторизации, GPU-квоты и недоступного Space. Подключение ограничено 30 секундами, ожидание очередного события — 150 секундами. Долгая активная очередь может продолжать присылать обновления; её можно остановить вручную.
- Инструменты: поиск по имени, описанию и ID, раскрытие версии и описания, обновление списка. «Как использовать» и «Показать код» только подготавливают сообщение: пользователь проверяет его и отправляет сам.
- Чаты сохраняются в текущем браузере. Поддерживаются экспорт, переименование, мобильная навигация, клавиатура и системное уменьшение анимаций.

## API и авторизация

Адрес Space задаётся в `index.html` через `meta[name="evomind-space"]`. Используются существующие `/respond_events`, необязательный `/respond_events_budgeted` и `/list_tools`.

`/list_tools` сейчас возвращает `tool_id`, `version`, `name`, `description`. Панель не выдумывает параметры или исходный код. Если API начнёт возвращать `input_schema`, `output_schema` или `source`, они также будут показаны как текст.

Вход через Hugging Face на основном домене использует существующий OAuth Client Metadata Document. Для localhost или отдельного preview-домена необходим зарегистрированный OAuth Client ID с подходящим redirect URI в `meta[name="evomind-oauth-client-id"]`. Секретный токен в HTML добавлять не нужно. Гостевой режим работает в пределах доступности и квоты Space.

## Проверки

```sh
npm test
npm run test:browser
```

Браузерный набор по умолчанию запускает установленный Google Chrome. Другой установленный Chromium можно выбрать переменной `PLAYWRIGHT_EXECUTABLE_PATH`; канал — `PLAYWRIGHT_CHANNEL`.

Проверяются ширины 320, 768, 1024 и 1440 px, форматирование и безопасность ответов, история, ошибки, повтор, остановка, offline-черновик, панель инструментов и фокус мобильной навигации. Проверки рабочей области покрывают таблицы, графики, числовые форматы, экспорт CSV, переключение видов и фокус. Скриншоты сохраняются в `test-results/`.

Тесты подменяют только транспорт Gradio контролируемыми ответами: GPU-квота не расходуется. Реальную генерацию модели и полноценный OAuth-вход нужно отдельно проверять на настроенном домене.
